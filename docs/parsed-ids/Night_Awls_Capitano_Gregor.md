**(×2)**

When this unit kills an enemy or breaks a Part, gain 2 Pierce Power Up next turn (once per turn) ; ; When using a Base Attack Skill, if this unit's Speed is faster than the target's, inflict Defense Power Down on the target for every 2 Speed difference (max 2 per turn) ; ; After ally Attack using Base Attack Skills, if the enemy(Core) has 20%- HP, use 'Mercé' on the target (once per turn) ; - If there is only 1 surviving enemy after an attack, this Passive also activates when the target is Staggered
